# 🚀 CODIMIUM CRM

### Lead Management System built with the MERN Stack

A modern, responsive and user-friendly CRM application designed to help businesses manage potential clients, track communication, organize follow-ups and monitor the complete sales pipeline.

---

## ✨ Features

### 🔐 Authentication & Security

- 📝 User Registration
- 🔑 User Login
- 🚪 Secure Logout
- 🔒 JWT Authentication
- 🔐 Password Hashing with bcrypt
- ✅ Form Validation
- 🛡️ Protected Routes
- 👤 Role-based access structure

---

### 📊 Dashboard

- 📈 Total Leads
- 🆕 New Leads
- 📞 Contacted Leads
- ❤️ Interested Leads
- 🤝 Meetings
- 🏆 Won Leads
- ❌ Lost Leads
- 📋 Recent Leads
- 📅 Follow-up Overview

---

### 👥 Lead Management

- ➕ Add new leads
- 📋 View all leads
- 👁️ View lead details
- ✏️ Edit lead information
- 🗑️ Delete leads
- 🔎 Search leads
- 🎯 Filter leads
- 👤 Assign leads to team members

---
